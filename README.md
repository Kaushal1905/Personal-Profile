# 🚀 Kaushal Tanna — Personal Portfolio

A modern, high-performance personal portfolio website built with pure HTML5, CSS3, and modern Vanilla JavaScript. Designed with a deep space aesthetic, subtle glassmorphism, responsive layouts, dynamic stat counters, interactive terminal typing, and smooth animations.

---

## 📸 Overview & Highlights

- **Aesthetic Design System** — Deep space dark palette (`#070913`, electric blue, neon violet, and mint emerald) with subtle SVG noise and grid overlays.
- **Flagship Project Showcase** — Live preview for **Arogya** smart OPD healthcare platform with direct Vercel deployment link (`https://arogya-india.vercel.app/`).
- **LeetCode & Problem Solving Spotlight** — Highlighting **150+ DSA problems solved in C++** with direct profile links.
- **Decoupled JavaScript Counter Engine** — Counter animations using HTML `data-target`, `data-decimals`, and `data-suffix` attributes with ease-out quartic physics.
- **Smart Custom Cursor** — Smooth LERP-interpolated trailing cursor that automatically activates on precision desktop pointers and safely disables on touch screens.
- **Mobile Responsive Drawer** — Custom hamburger navigation menu for smooth navigation on mobile screens.
- **Direct Resume Access** — Hero and navigation buttons for instant resume download (`Kaushal Resume(main).pdf`).

## 🛠️ Tech Stack

| Layer | Technologies |

## 🚀 Getting Started

### Option 1 — Open Directly in Browser
Double-click `index.html` in your file explorer. It opens in any modern web browser immediately.

### Option 2 — Run with a Local Web Server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
Visit `http://localhost:8000` in your browser.

## 🌐 Free Deployment Guide

You can easily deploy this portfolio live for free:

### Deploy to Vercel (Recommended):
1. Push this folder to a GitHub repository.
2. Visit [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository — Vercel detects static HTML automatically.
4. Click **Deploy**. Your portfolio will be live at `kaushaltanna.vercel.app`!

### Deploy to GitHub Pages:
1. Push to your GitHub repo (e.g., `github.com/kaushal1905/Personal-Profile`).
2. Go to **Settings** → **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
